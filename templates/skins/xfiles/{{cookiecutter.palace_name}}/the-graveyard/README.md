# the-graveyard

*Where completed subprojects rest. The work happened. The trace remains.*

Each subdirectory is a completed project — at rest, not active. Named by project and year of completion.

## Convention

```
the-graveyard/
  project-name-YYYY/
    README.md    ← outcome, date completed, why it's here
    ...          ← original project files
```

To move a subproject here: complete the work, write the README, move the directory. That's it.

*The graveyard is not a trash bin. It's an archive with intention.*
